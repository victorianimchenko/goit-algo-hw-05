# goit-algo-hw-05

# Порівняння алгоритмів пошуку підрядка

У цьому завданні було проведено порівняння трьох алгоритмів пошуку підрядка:

* Boyer-Moore;
* Knuth-Morris-Pratt;
* Rabin-Karp.

Для вимірювання часу виконання використовувався модуль Python `timeit`.

Тестування проводилося на двох текстових файлах. Для кожного тексту використовувалися два типи підрядків:

1. підрядок, який дійсно існує в тексті;
2. вигаданий підрядок, якого в тексті немає.

Кожен алгоритм запускався багаторазово, після чого визначався середній час одного виконання.

## Використані підрядки

### Стаття 1

Існуючий підрядок:

`експоненціальний пошук використовується`

Вигаданий підрядок:

`квантовий пошук у зеленому лабіринті`

### Стаття 2

Існуючий підрядок:

`профілювання тестового коду показало`

Вигаданий підрядок:

`квантова база даних зоряного каталогу`

## Результати тестування

| Текст    | Тип підрядка | Boyer-Moore, с |     KMP, с | Rabin-Karp, с |
| -------- | ------------ | -------------: | ---------: | ------------: |
| Стаття 1 | Існуючий     | **0.00007485** | 0.00063106 |    0.00106333 |
| Стаття 1 | Вигаданий    | **0.00014650** | 0.00111920 |    0.00181367 |
| Стаття 2 | Існуючий     | **0.00014477** | 0.00117472 |    0.00209344 |
| Стаття 2 | Вигаданий    | **0.00020138** | 0.00164750 |    0.00288844 |

## Аналіз результатів

### Стаття 1

Для існуючого підрядка найшвидшим виявився алгоритм **Boyer-Moore** з часом `0.00007485` секунди.

KMP виконав пошук за `0.00063106` секунди, а Rabin-Karp — за `0.00106333` секунди.

При пошуку вигаданого підрядка Boyer-Moore також показав найкращий результат — `0.00014650` секунди. KMP потребував `0.00111920` секунди, а Rabin-Karp — `0.00181367` секунди.

Таким чином, для першої статті найефективнішим в обох випадках став алгоритм Boyer-Moore.

### Стаття 2

Для існуючого підрядка найшвидшим також був **Boyer-Moore** з результатом `0.00014477` секунди.

KMP виконав пошук за `0.00117472` секунди, а Rabin-Karp — за `0.00209344` секунди.

Для вигаданого підрядка Boyer-Moore показав час `0.00020138` секунди, KMP — `0.00164750` секунди, а Rabin-Karp — `0.00288844` секунди.

Отже, для другої статті Boyer-Moore також виявився найшвидшим алгоритмом незалежно від того, чи існував підрядок у тексті.

## Порівняння алгоритмів

За результатами всіх чотирьох тестів алгоритми розташувалися за швидкістю таким чином:

1. **Boyer-Moore**
2. **Knuth-Morris-Pratt**
3. **Rabin-Karp**

Boyer-Moore показав значно менший час виконання в кожному з проведених тестів.

Також можна помітити, що для всіх алгоритмів пошук вигаданого підрядка займав більше часу, ніж пошук вибраного існуючого підрядка. Це пов'язано з тим, що при відсутності підрядка алгоритму необхідно продовжувати пошук далі по тексту, замість того щоб завершити роботу після знаходження збігу.

## Висновок

У результаті проведеного тестування найшвидшим алгоритмом пошуку підрядка для обох текстів став **Boyer-Moore**.

Для статті 1 він показав найкращий час як для існуючого підрядка (`0.00007485` с), так і для вигаданого (`0.00014650` с).

Для статті 2 Boyer-Moore також був найшвидшим: `0.00014477` с для існуючого та `0.00020138` с для вигаданого підрядка.

Алгоритм Knuth-Morris-Pratt посів друге місце за швидкістю, а Rabin-Karp у проведених тестах показав найбільший час виконання.

Таким чином, для використаних текстів і вибраних підрядків алгоритм **Boyer-Moore є найефективнішим як для кожного тексту окремо, так і в цілому**.

Водночас отримані результати залежать від характеристик тексту, довжини та розташування підрядка, його вмісту та конкретної програмної реалізації алгоритмів, тому результати інших тестів можуть відрізнятися.
